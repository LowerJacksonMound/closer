# Security

Report a security problem privately first. Use GitHub's private vulnerability reporting on this repository
(Security tab, "Report a vulnerability"), or contact the owner, LowerJacksonMound, through GitHub. Do not open a
public issue for it until a fix is out.

A report carries what the README's "Reporting a problem" section names, plus what the problem lets someone do.

A fix ships as a new version; no released tag is moved. There is no bug bounty.

Closer: how to use it on a Mac
==============================

What a friend on macOS has to do

1. Have the prerequisites.
   A Mac, since the gate uses the macOS sandbox (sandbox-exec).
   Python 3.10 or newer with pytest importable.
   Claude Code installed and signed in, with `claude` on PATH.
   A Python repo whose tests pass.

2. Copy this folder anywhere and put the front door on PATH:

       ln -s "$PWD/closer" /usr/local/bin/closer

3. Check the machine:

       closer doctor

   It reports the sandbox, the Python, pytest, Claude Code, and whether that
   Claude build supports the restricted flags the writer session needs.

4. See it work:

       closer demo

   About a minute on a bundled sample repo, with the page at http://localhost:8766/

5. Use it on your repo: cd into it, write a task, fill the placeholders, then go:

       cd your-repo
       closer task add-thing        # writes add-thing.md; fill every <FILL: ...>
       closer go add-thing.md

No pip install, no requirements file. The code is the Python standard library plus
pytest. There are no hardcoded paths to the author's machine in the code.

Two things worth knowing

- The writer session runs through your own Claude Code login, so it uses your
  account and your usage.
- The folder is about 16 MB, and 14 MB of that is the spec (CLOSER_SPEC_2026-10-10)
  and the film draft (CLOSER_FILM_DRAFT), which you can ignore.

Other commands

    closer claims TASK.md    draft and show the claims, mint nothing
    closer go TASK.md --chat an interactive writer session: you type the request yourself
    closer status            the page as text, with the next step
    closer inspect [TICKET]  one ticket's verdict in words
    closer amend             show or change the interpreter and test folder the repo was registered with
    closer watch             watch the repo for edits made outside the gate
    closer stop              stop the page and the watcher
    closer forget --gone     remove the state of repos that no longer exist

The five-minute version is QUICKSTART.md. The long version, with the rules the gate
follows, is README.md and KERNEL.md.
